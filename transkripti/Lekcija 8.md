**What is an IDE?**





For this course, we're going to use an IDE called IntelliJ IDEA.



An IDE, or Integrated Development Environment, is the tool that we use to write programs.



The main feature is a text editor, that we type our code into.



But an IDE also compiles and runs our programs for us.



When I started programming, we didn't have IDEs,



we had to perform each step manually. After editing the code and saving it,



we'd exit the editor and run the compiler to compile the code.



Once the code had compiled, we could run it. If there were errors, we'd have to go



back into our text editor to make corrections, and repeat the process.



An IDE makes all that much easier, we can edit and run the code without leaving the IDE.



And as you'll see, it also warns us about errors in our code, before we run it.



I mention all that because students often ask why we need an IDE â€“ so that's why.



So an IDE gives us all the tools we need, in one place.



We write or edit our code, then run it with a simple menu option or button.



If there are any errors, we might even get a warning from the IDE before we run the code.



Because we don't have to leave our IDE, we can easily make changes and run the code again.



The IDE we're going to use is called IntelliJ IDEA, created by a company called JetBrains.



There are other IDEs available, and we've listed some popular ones on the slide.

and you're comfortable using, then it's fine to continue using it.
